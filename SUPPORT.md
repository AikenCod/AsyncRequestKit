# Support

AsyncRequestKit is maintained as a community open-source project without a
guaranteed response time or private integration support.

Use the repository's GitHub issue forms for:

- reproducible defects in AsyncRequestKit;
- focused API and installation questions;
- feature proposals tied to a concrete user problem.

Before opening an issue, search existing issues and reduce the problem to a
small reproduction. Include the package version, Swift version, target
platform, expected behavior, and actual behavior.

Report security concerns privately as described in [SECURITY.md](SECURITY.md).
Do not include credentials, proprietary source code, customer data, or private
server responses in public issues.
