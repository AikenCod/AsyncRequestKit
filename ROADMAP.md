# Roadmap

This roadmap describes intended outcomes, not promised dates. Work is accepted
only when it solves a real project need and has appropriate verification.

## 0.5.0 — Portability and Trust

- Linux CI and `FoundationNetworking` compatibility
- MIT metadata and maintainer policies
- clean-consumer verification
- release consistency checks

## 0.6.0 — Documentation and Distribution

- DocC catalog and Swift Package Index listing
- authentication, retry, and upload integration guides
- verified CocoaPods installation
- evidence ledger for compatibility and distribution claims

## 1.0.0 — Stable API

- public API review and compatibility policy
- migration guide from `0.6.x`
- adopter feedback incorporated through linked, legitimate issues
- documented long-term support expectations

Roadmap items may be reordered when security, compatibility, or real adopter
feedback provides stronger evidence of priority.
