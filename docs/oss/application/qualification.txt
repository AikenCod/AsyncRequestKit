AsyncRequestKit is an MIT-licensed Swift 6 concurrency networking toolkit I created and maintain. Release 0.5.0 has macOS/Linux CI, 28 tests, clean SPM and CocoaPods lint checks, bilingual docs, DocC, security and contribution policies, and no API breaks versus 0.4.0. It covers retry, timeout, bounded concurrency, cache/queue, token refresh, and multipart. Adoption is currently modest (1 star), and I will not overstate it.
